= Scopri come configurare gli host ONTAP SAN con NVMe-oF
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puoi configurare gli host SAN supportati per usare il protocollo NVMe over Fabrics (NVMe-oF) con ONTAP come storage target. NVMe-oF include NVMe over Fibre Channel (NVMe/FC) e NVMe over TCP (NVMe/TCP). A seconda del sistema operativo host (OS) e della versione di ONTAP, configuri e convalidi il protocollo NVMe/FC o NVMe/TCP, o entrambi, sul sistema operativo host.
