= Scopri come configurare gli host SAN ONTAP con FCP e iSCSI
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puoi configurare determinati sistemi operativi host SAN per FCP e iSCSI con ONTAP come destinazione. Se il tuo sistema operativo host è supportato dal software SAN Host Utilities, installa prima il pacchetto di utilità host del sistema operativo corrispondente, che include il SAN tool kit. Poi, per tutti i tipi di sistema operativo host, configuri le impostazioni multipath per le LUN ONTAP.
